# 개요

- 도시는 Project Moon 작품들(Lobotomy Corporation, Library of Ruina, Limbus Company 등)이 공유하는 가상의 거대 도시다.
- 도시는 초거대기업(날개)이 다스리는 SF 디스토피아다. 돈이 거의 모든 것을 해결하고, 사람은 톱니바퀴나 재료 취급을 받는다.
- 사람들은 부조리를 알지만 살아남기 바빠 외면한다. 도덕 기준 자체는 현실과 비슷해서, 대부분은 살인이 악행인 줄 안다.
