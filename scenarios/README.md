# 시나리오

바다거북스프 시나리오를 둔다. 시나리오 1개 = 파일 1개(`<slug>.md`).

## frontmatter
- `id`: `scenario.<slug>`
- `title`: 시나리오 제목
- `difficulty`: easy / normal / hard
- `era`: 배경 시대 ID (`world/base/08-eras.md`)
- `works`: lobotomy / ruina / limbus / other
- `uses`: 근거가 된 상세 항목 ID 목록 (`world/detail`). 판정 때 함께 불러온다.
- `updated`: YYYY-MM-DD

## 본문
1. **문제**: 플레이어에게 보여 주는 짧은 이야기. 진상은 숨긴다.
2. **진상**: 전말. AI가 예/아니오를 판정하는 기준이다. 플레이어에게 보여 주지 않는다.
3. **핵심 키워드**: 정답 조건. 추리가 모두 담아야 정답이다. 아래 형식을 따른다.
4. **보너스 키워드**: 정답과 상관없는 곁가지 사실 1~2개. 맞히면 보너스다.
5. **판정 메모**: 헷갈리기 쉬운 질문과 답. 답은 예 / 아니오 / 일부만 맞다 / 조건이 붙으면 예다 / 상관없음 / 정해지지 않음 가운데 하나로 쓴다(판정 코드와 하나씩 맞는다). 진상에 없는 일이나 사람이 관련됐냐는 질문은 아니오, 진상에 나온 일의 정하지 않은 세부는 정해지지 않음, 사건에 없는 대상의 성질은 상관없음이다. '왜', '어떻게' 질문은 반려되니 메모에 넣지 않는다.
6. **힌트**: 약한 것부터 3단계.

### 핵심 키워드 형식
```markdown
## 핵심 키워드
1. **거주구역 등록 만료**: 건물의 거주구역 등록 기한이 지나 거주구역이 아니게 되었다.
   - 들어가야 할 것: 건물의 거주구역 등록이 끝나 거주구역이 아니게 되었다
   - 필수 용어: 거주구역
   - 인정: 거주구역 등록이 끝났다, 거주구역에서 빠졌다, 거주구역 갱신을 안 했다
   - 불인정: 허가가 끝났다, 계약이 끝났다, 집으로 인정받지 못했다
   - 빠졌을 때: 건물주가 무엇을 했는지가 빠져 있구나.
```
- 한 키워드에는 사실 하나만 담는다. 여러 사실을 한 줄에 묶으면 채점이 깐깐해진다.
- **들어가야 할 것**: 답안에 **모두** 있어야 충족인 내용. 한 줄에 하나씩 적는다(여럿이면 줄을 나눈다, 쉼표로 묶지 않는다). 뜻이 같으면 다른 말이어도 되지만, 내용 없이 성질만 말하면("불가능한 부탁을 했다") 충족이 아니다. 괄호 안은 있으면 좋지만 없어도 되는 말이다. 세계관 용어를 낱말 그대로 요구하려면 필수 용어에 적는다.
- **필수 용어**(선택): 이 세계관 용어를 정확히 써야 충족이다. 대상은 세계관을 아는 팬이다. 여러 개면 쉼표로 나눈다.
- **인정 / 불인정**: 충족으로 볼 표현과 아닌 표현의 예. 쉼표로 나눈다.
- **빠졌을 때**(선택, 지금은 쓰지 않음): 예전에는 이 키워드를 못 맞히면 화면에 보여 줬다. 추리가 너무 쉬워져서 지금은 빠진 개수에 따른 응시자의 한마디만 보여 주고 이 문장은 읽지 않는다. 적어 두어도 된다.
  - **문제에 이미 나온 내용만** 언급한다(인물, 물건, 겉으로 드러난 사건).
  - 키워드 이름, 필수 용어, 세계관 용어, 진상에만 있는 사실은 쓰지 않는다. 이 문장이 힌트가 되면 안 된다.
  - 나쁜 예: "어떻게 그 집이 무방비가 되었는지가 빠져 있구나." / 좋은 예: "건물주가 무엇을 했는지가 빠져 있구나."

### 보너스 키워드 형식
```markdown
## 보너스 키워드
- **월세 체납**: 세입자들은 1년 넘게 월세를 밀리고 있었다. 건물주는 그 일로 오래 앙심을 품었다.
- **증거가 남지 않음**: 청소부가 모든 것을 쓸어 가서 증거가 남지 않았다. 그래서 건물주는 처벌받지 않았다.
```
- 반전이나 핵심 키워드와 직접 관련 없는 곁가지 사실이다. 이 곁가지를 빼도 핵심 키워드는 그대로여야 한다.
- 진상에 이미 있는 곁가지(예: 처벌받지 않은 이유)를 쓰거나, 새 곁가지(예: 인물의 사정)를 만든다.
- 새 곁가지는 **진상과 판정 메모에도 적는다.** 그래야 질문으로 알아낼 수 있다. 세계관 설정은 지어내지 않는다.

진상은 `world/`에 정리된 사실만으로 만든다. 새 설정을 지어내지 않는다.

## 이미지
시나리오 그림은 `scenarios/images/<slug>/`에 넣는다. slug는 시나리오 파일 이름(확장자 없이)이다.

| 파일 이름 | 쓰이는 곳 |
|---|---|
| `cover` | 사건 목록 카드, 사건 기록 위쪽(대표 이미지) |
| `hint-1`, `hint-2`, `hint-3` | 그 계시(힌트) 줄 안 |

- 확장자는 `webp`, `png`, `jpg` 중 하나(같은 이름이 여럿이면 이 순서로 고른다). 한 장에 500KB 안쪽을 권한다.
- 그림이 없으면 글자만 보인다. 서버를 다시 켜지 않아도 넣은 그림이 바로 보인다.
- **그림이 진상을 흘리면 안 된다.** 문제 표면에 세계관 키워드를 드러내지 않는다는 규칙을 그림에도 똑같이 적용한다. 힌트 그림은 그 힌트 문장보다 더 많이 알려 주지 않는다.
- 프로젝트 문 공식 그림(캐릭터, 로고, 일러스트)은 쓰지 않는다. 새로 만든 그림만 쓴다.
