# 화면 배치: 클립보드 사건 기록과 무전기 조작판 (짧은 설계)

## 의도
수신 기록 칸이 너무 크고 사건 기록이 작다. 사건 기록을 키우고, 사건 기록과 입력칸(질문하기·추리 제출)도 주시자 무전 콘셉트에 맞게 바꾼다.
시안: `.superpowers/brainstorm/.../layout.html`의 B(사용자 선택).

## 사용자 결정
- 사건 기록 : 수신 기록 = **50 : 50**.
- **수신 기록 화면 안쪽은 지금 그대로**(바탕, 주사선, 흐르는 띠, 머리, 줄 모양과 색, 연출). 폭만 줄어든다.
- 사건 기록은 **클립보드**(갈색 판, 위쪽 금속 집게, 끼운 서류). 서류 머리 "사건 기록"과 위험 등급, 제목, 대표 이미지(없으면 숨김), 문제, "힌트 요청 (사용 N으로)", "포기하고 진상 보기".
- 수신 기록 바깥에 **무전기 몸체** 테두리, 그 아래 **조작판**: "질문"·"추리" 기계 버튼, 녹색 액정 입력칸, "송신 ▶" 버튼.

## 내가 채운 것
- 좁아진 수신 기록에서 질문과 답이 한 줄에 안 들어가면 답이 질문 아래 오른쪽으로 내려간다(겹치지 않게). 이것 말고 수신 기록 안쪽 스타일은 바꾸지 않는다.
- 추리 모드: 액정이 여러 줄로 커지고 조작판 아래 "추리는 사용 5를 씁니다."
- 마지막 기회: "질문" 버튼 잠김, 액정 위 "질문을 모두 썼습니다. 마지막 추리 기회가 한 번 남았습니다."
- 답을 기다리는 동안: "송신" 버튼이 눌린 모양의 "수신 대기".
- 글자 수·Enter 안내는 조작판 아래 작게.
- 게임이 끝나면 조작판 자리에 지금처럼 진상 공개 보고서.
- 좁은 화면(760px 이하): 지금처럼 위아래로 쌓는다.
- 서류 머리는 "사건 기록"만 쓴다. 게임 화면은 사건 번호(목록 순서)를 모른다(GameView에 없다). 번호를 넣으려면 API를 바꿔야 해서 이번에는 뺀다.

## 바꾸지 않는 것
게임 규칙, 서버, API, 수신 기록 안쪽 스타일, 버튼과 입력의 동작(접근성 이름 "질문하기"·"추리 제출" 탭, "질문" 입력칸 포함).

## 방법
CSS와 화면 구조만 바꾼다. 기존 테스트가 쓰는 접근성 이름(탭 이름, 입력칸 이름, 버튼 이름 규칙)은 유지해서 동작 테스트가 그대로 통과하게 한다. 그래서 바꿀 것은 화면 모양뿐이고 방법은 하나다.

## 추가 결정 (2026-11-25, 같은 브랜치)
시안: `panel-v2-modal.html`.

### 조작판: A1 "홀로그램 송신 단말"
- 모서리가 비스듬히 잘린 판, 빨간 네온 테두리, 안쪽 옅은 주사선, 머리에 `송신 단말 // CH-07`과 신호 막대(사용 횟수에 따라 켜짐).
- "질문"·"추리" 버튼과 "송신" 버튼은 굵고 각진 글꼴(**Black Han Sans**), 입력칸·안내 줄은 코딩체(**Nanum Gothic Coding**). 켜진 버튼과 송신 버튼은 빨간 바탕에 빛.
- 입력칸은 검은 바탕에 깜빡이는 빨간 커서 느낌, 명령조 문구: 질문 `예나 아니오로 답할 수 있는 질문을 입력하라`, 추리 `사건의 전말을 송신하라. 무엇이 일어났고, 누가 왜 그랬는지.`
- 아래 줄: `0/200 // 모든 송신은 기록된다`와 오른쪽 `사용 n/40`. 추리 모드 비용 안내와 마지막 기회 안내는 지금 문구 그대로.
- 내 결정: 시안의 영어 작은 글자(`TRANSMIT`)는 빼고 한국어만 쓴다(CLAUDE.md 규칙).

### 힌트: 사용 막대에서 받고, 계시창에서 본다
- 사용 막대의 힌트 눈금이 버튼이 된다. 노란색 `계시 N`(열림)은 누르면 계시창, 점선 `계시 N 요청 (사용 M으로)`(다음)은 누르면 힌트 요청, 회색 `계시 N`(잠김)은 누를 수 없다.
- **계시는 수신 기록 줄에 남기지 않는다.** 클립보드의 "힌트 요청" 버튼도 없앤다(막대로 옮김).
- **계시창**: 화면 가운데 창(뒤는 흐리게). 위에 계시 그림(있을 때만), 아래 계시 문장, 맨 아래 열린 계시끼리 넘기는 버튼과 `닫기`. Esc나 창 바깥을 눌러도 닫힌다. **계시가 새로 열리는 순간**(질문·추리·힌트 요청으로 열림) 계시창이 자동으로 뜬다(사용자 결정). 처음 불러온 게임에서 이미 열려 있던 계시는 자동으로 뜨지 않는다.
- 접근성: 계시창은 `role="dialog"`·`aria-modal`, 열리면 닫기 버튼에 초점, 닫으면 누른 눈금으로 초점을 돌려준다.
- 백엔드는 바꾸지 않는다(힌트 seq는 그대로 내려오고, 화면이 쓰지 않을 뿐이다).
